## 💡 Common Questions Answered

### "Where do I start?"
1. Read COMPLETION_SUMMARY.md (5 min)
2. Run `npm install && npm run dev`
3. Visit http://localhost:3000/internships/apply
4. Fill out the test form

### "How do I customize the colors?"
1. Open `src/app/globals.css`
2. Find `:root { --navy: ...`
3. Change the color values
4. Restart dev server

### "How do I deploy?"
1. Read DEPLOYMENT_GUIDE.md
2. Choose a platform (Vercel recommended)
3. Follow platform-specific steps
4. Test on production

### "Something's broken!"
1. Read TROUBLESHOOTING.md
2. Check browser console (F12)
3. Try the debugging checklist
4. Google the error message

### "What if I need to add a new field?"
1. Read SETUP_GUIDE.md → "Add New Form Step"
2. Add Zod schema in `src/schemas/applicationSchema.ts`
3. Create component
4. Add to main form page

### "How do I connect my API?"
1. Update `.env.local` with API URL
2. Restart dev server
3. API calls happen automatically
4. Check Network tab (DevTools) to verify
